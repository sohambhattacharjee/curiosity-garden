# Question-bank review — draft PR

This PR is separate from app implementation. The current 96 questions are development placeholders. None has been approved for Release. The owner, Soham Bhattacharjee, will review questions; no draft may be marked reviewed merely because automated tests pass.

## Review process

1. Replace placeholder wording where needed; verify the answer and explanation using appropriate primary references.
2. Check content difficulty separately from selected-grade reading needs. The current `readingGrade: 0` values are placeholders, not a readability assessment.
3. Confirm original authorship or MIT-compatible rights and preserve required notices.
4. Check ambiguity, distractors, accessibility, and visual descriptions. Keep two to four distinct choices and one correct answer.
5. Only after the owner's actual review, add real references, reviewer identity, and review date to the question and set `status` to `reviewed`. Keep unanswered review rows as draft.
6. Verify enough school/general material exists at every supported content level and reading ceiling before a family-ready Release. Bank updates arrive through app updates.

No app behavior, timers, review gate, or typography changes are included in this content PR. Release continues to exclude drafts. Do not add a bypass to make a sparse bank playable.
